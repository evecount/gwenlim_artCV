## 👋 About Gwen

Hi, I'm Gwen — an artist, computational systems architect, and maker based in Singapore.

For the past 16 years (spanning Toronto and Singapore), my practice has lived at the intersection of photography, physical computing, custom electronics, and participatory spatial installations. 

I investigate how cameras and observation systems shape human behavior, how we interact with technology when it is tactile and physical rather than locked inside screens, and how grassroots artist communities build independent creative infrastructure together.

## 🎨 Selected Works & Installations (2010 — 2026)

### 2010–2012 · White Geisha & Silver Aurelia
* **Venue / Context:** *Noise Singapore Festival Exhibition*, ION Orchard, National Arts Council (Singapore)
* **Medium:** Curated photographic series, archival pigment prints (Nikon D1X, studio lighting)
* **Focus:** Staged portraiture, persona construction, and human vulnerability under institutional observation. Explored how studio lighting and surface ornamentation mediate the observer's gaze.

### 2011 · A Perfect World
* **Venue / Context:** Kensington Market Cultural Commons, Toronto (with Akin Collective)
* **Medium:** Street-level relational intervention, dialogue, and portraiture (Nikon D1X)
* **Focus:** Engaging neighborhood residents, independent shopkeepers, and passersby in conversations about personal sanctuary during rapid urban change, using deliberate portraiture to establish mutual trust rather than candid extraction.

### 2012 · Two-Man Rule [TMR]
* **Venue / Context:** TEDxToronto, The Sony Centre for the Performing Arts
* **Medium:** Walk-in geodesic tape monocoque dome (over 300 rolls of tape), dual palm-contact switches, custom camera rig
* **Focus:** Relational interdependence. Fabricated in collaboration with Toronto's **Akin Collective**, the installation required two complete strangers to stand across the dome and simultaneously press their palm triggers to capture a shared photograph.

### 2012 · Broadcast People
* **Venue / Context:** |FAT| Toronto Alternative Arts & Fashion Week
* **Medium:** Video installation with 16 stacked CRT television monitors, CCTV cameras, and concealed floor pressure-plate switches
* **Focus:** Surveillance and self-broadcast. Stepping onto hidden floor switches immediately routed the visitor's live feed across the entire CRT monitor stack, collapsing the distinction between audience and observed subject.

### 2013–2014 · The Ultimate Selfie & Interactive Pavilions
* **Venue / Context:** Metro Toronto Convention Centre (Interior Design Show / IIDEX / Toronto Design Offsite)
* **Medium:** Custom interactive pavilion, hacked Canon 5D Mark II, optocoupler electronic trigger boards, real-time architectural projection
* **Focus:** Pre-smartphone automated selfie culture. Visitors activated studio flashes and cameras via physical tactile triggers, projecting raw, unedited portraits directly onto architectural scrims.

### 2020 · Deconstructing Capital
* **Venue / Context:** 52 St. Lawrence Studio, Toronto
* **Medium:** Site-specific spatial lighting intervention, theatrical Fresnel wash lights, polyethylene optical scrims
* **Focus:** Optical saturation and architectural boundaries. Explored how focused light can simultaneously expose a volume and carve out private, reflective enclosures shielded from passive surveillance.

### 2011–2024 · Motion and Still & Studio Stewardship
* **Context:** Toronto Studio Network (Gladstone, Midcentury, Plant Paradise, 90 Ontario, Florence) & Flick the Switch Collective
* **Focus:** Over a decade of grassroots artist-run infrastructure. Directed *Motion and Still* across four overlapping live/work loft studios, providing shared production resources, hosting community acoustic sessions (Sofar Sounds), and delivering commercial production for 39 selected clients across 6 sectors. Served as long-term media and documentation lead for *Flick the Switch Artists' Collective*.
* **Archival Dossier:** Complete studio network locations, client roster, pro bono mutual aid, and foundational operations (2008–2024) are documented in [`MOTION_AND_STILL_INC.md`](MOTION_AND_STILL_INC.md).

### 2026 · The Riemann Manifold
* **Context:** Independent Computational Practice
* **Medium:** Algorithmic visualization, spatial projection, and audio-harmonic synthesis
* **Focus:** Computational aesthetics and non-human mathematical order, mapping the non-trivial zeros of the Riemann zeta function to harmonic wave structures and spectral geometry.

## 💻 About this Monograph Web App

This repository hosts Gwen's interactive curatorial portfolio and document reader:

* **Engine:** TanStack Start, React 19, TypeScript, Tailwind CSS, Vite.
* **Architecture:** Full route-based navigation (`/`, `/statement`, `/works/$artworkId`, `/timeline`, `/cv`, `/residency`).
* **Document Engine:** 4-page A4 landscape Curriculum Vitae and 2-page Statement of Interest formatted with print stylesheets.

### Running Locally

```bash
# Clone the repository
git clone https://github.com/evecount/gwenlim_artCV.git
cd gwenlim_artCV

# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build for production
npm run build
```
